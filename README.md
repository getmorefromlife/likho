# قلم و قافیہ | Qalam & Qafiya (Likho)
> **اسٹوڈیو برائے شعر و ادب، فنِ عروض و معجمِ قوافی**  
> An enterprise-grade, classical Urdu poetry workstation featuring deterministic prosody scansion, a 40,434-key source-attributed offline pronunciation dictionary, an algorithmic reverse-rhyme engine, an interactive visual slot/wildcard builder, and client-side multi-format file ingestion.
>
> 📖 **[مکمل تکنیکی دستاویزات و انجینئرنگ گائیڈ (Full Technical Architecture & Manual)](DOCUMENTATION.md)**

## 🌟 کلیدی خصوصیات (Key Features)

### ۱. قطعی عروضی انجن اور اصلاح
- اعراب محفوظ رکھتے ہوئے تقطیع، اضافت، تشدید، نونِ غنہ، ہمزہ، وصل اور جائز تخفیف کی جانچ۔
- ایک مشترک فہرست میں ۵۰ ماخذ دار اوزانی صورتیں؛ ہر منتخب قرأت کا تلفظ اور ماخذ قابلِ مشاہدہ ہے۔
- اصل مصرع دوبارہ تقطیع ہونے کے بعد ہی وزنی بہتری کی تجویز دی جاتی ہے؛ جزوی اصلاح اور مکمل مطابقت الگ دکھائی جاتی ہیں۔
- مثال: کلام کا متصل وزن `- = -` ہے۔ نامعلوم تلفظ کے لیے اندازے سے وزن نہیں بنایا جاتا۔

### ۲. ماخذ دار آف لائن لغت
- Aruuz کی معین اشاعت سے ۴۰،۴۳۴ لغوی کلیدیں اور ۴۳،۵۵۶ قرأتیں، اصل اندراج کے حوالے سمیت۔
- ۱،۰۰۷ غیر معاون یا ناممکن اندراجات الگ قابلِ جانچ فہرست میں محفوظ ہیں۔ یہ تعداد ہر اندراج کی آزاد علمی توثیق کا دعویٰ نہیں۔
- عام لفظی فائلوں سے الفاظ محفوظ ہوتے ہیں، فرضی اوزان نہیں۔ ذاتی اوزان غیر مصدقہ حیثیت کے ساتھ الگ رہتے ہیں۔
- GPL-2.0 ماخذ، اجازت نامہ اور قابلِ تدوین لغوی مواد ایپ کے ساتھ شامل ہیں۔
- مکمل معاہدہ، حدود اور جانچ: [PROSODY_REPAIR.md](PROSODY_REPAIR.md)۔

---

### ۳. خودکار معجمِ قوافی (Algorithmic Reverse-Rhyme Engine)
- **حرفِ روی و آواز کا اخراج (Suffix Extraction):** کسی بھی لفظ کے آخری حرف اور ماقبل حرکت (ام، ان، ار، ات، یت، ال، اب، ور، یر، وغیرہ) کی ریاضیاتی شناخت۔
- **بحور و اوزان کے مطابق درجہ بندی:** قوافی کو اوزان کے مطابق خانوں میں پیش کرنا (مثلاً: `فَعُولْ`، `فَعِیلَت`، `فَاعِلُن`، `مُسْتَفْعِلُن`)۔
- **فَعِیلَت کا کلاسیکی رول:** تانیثی قوافی (حقیقت، بصیرت، شریعت، طریقت، طبیعت، غنیمت، عزیمت) کا باہمی ربط۔
- **کلام سے خودکار تشخیص:** کینوس پر لکھے گئے اشعار سے ردیف اور قافیہ خودکار پہچان کر فوری ہم قافیہ الفاظ پیش کرنا۔

---

### ۴. انٹرایکٹو قالب سازِ قوافی (Visual Slot / Wildcard Rhyme Builder)
- **خانہ وار تقسیم (Visual Letter Slots):** لفظ کو الگ الگ کلک ایبل خانوں میں بانٹنا:
  $$\boxed{\text{ا}} \quad \boxed{\text{ی}} \quad \boxed{\text{م}} \quad \boxed{\text{ا}} \quad \boxed{\text{ن}}$$
- **۳ فیز کا انٹرایکٹو ٹوگل:**
  1. **مستقل (Lock):** سنہری رنگ — یہ حرف اسی پوزیشن پر لازمی ہوگا۔
  2. **وائلڈ کارڈ (`*` Any Letter):** ڈیشڈ بارڈر — اس جگہ کوئی بھی اردو حرف آ سکتا ہے۔
  3. **حرفِ علت / حرفِ صحیح:** صرف علت (`ا، و، ی، ے`) یا صرف صحیح حروف۔
- **کلاسیکی پری سیٹس:** ایک کلک پر *صرف حرفِ روی*، *مردف (ردف و روی)*، یا *تاسیس و دخیل*۔
- **اوزان و طوالت کے فلٹرز:** پابندِ طوالت یا آزاد طوالت اور مخصوص بحر کے افاعیل کا انتخاب۔
- **ہائی اسپیڈ ریجیکس:** فعال لغت پر ریجیکس سے نتائج تلاش کرنا؛ کوئی غیر ماپا وقت ضمانت کے طور پر نہیں دیا جاتا۔

---

### ۵. کلائنٹ سائیڈ فائل درآمد انجن (ODT, TXT, CSV Ingestion)
- **سپورٹڈ فارمیٹس:** `.txt` (پلین ٹیکسٹ UTF-8)، `.csv / .tsv` (اسپریڈ شیٹ و فہرست)، اور `.odt` (اوپن ڈاکومنٹ ٹیکسٹ)۔
- **بغیر سرور کے براؤزر میں انضمام:** کلائنٹ سائیڈ پر `content.xml` اور ٹیکسٹ اسٹریم پڑھ کر فوری الفاظ کشید کرنا۔
- **تکرار کی مکمل ممانعت (Zero Duplicates Guarantee):** ڈپلیکیٹس اور اعراب صاف کر کے صارف کے محفوظ ذاتی بینک (**IndexedDB: میرا ذاتی ذخیرہ**) میں محفوظ کرنا۔

---

### ۶. ان-ایپ اردو صوتی کی بورڈ انجن (CRULP / NLA Standard)
- **آپریٹنگ سسٹم کی سیٹنگ بدلے بغیر ٹائپنگ:** معیاری انگریزی (QWERTY) کی بورڈ پر براہِ راست روانی سے اردو لکھنا۔
- **مکمل نقشہ کشی:** تمام حروف، اعراب (زبر، زیر، پیش، جزم، تشدید) اور رموزِ اوقاف (`؟`, `،`, `؛`, `۔`)۔
- **شارٹ کٹس و نیوی گیشن:**
  - آن / آف شارٹ کٹ: `Ctrl + Space` یا `Alt + K`۔
  - ٹول بار میں گولڈن گلائی بٹن `[⌨️ صوتی کی بورڈ: آن / آف]`۔
  - مکمل تصویری نقشے کے لیے "کی بورڈ گائیڈ ماڈل"۔
  - سسٹم کے تمام شارٹ کٹس (`Ctrl+C`, `Ctrl+V`, `Cmd+Z`) کی حفاظت۔

---

### ۷. نستعلیق ٹائپوگرافی و ڈسٹریکشن فری کینوس (Poetry Canvas)
- **اعراب و نقطوں کا تحفظ:** ۲.۶ سے ۲.۸ کی کشادہ لائن ہائٹ اور ان کلپڈ پیڈنگ، جس سے نقطے کٹتے نہیں۔
- **فی مصرع تقطیع کارڈز:** ہر مصرع کے نیچے اصل ہجے، ماخذ، جوازات اور منتخب بحر سے مطابقت۔
- **ورڈ پروسیسر ٹول بار:** سرخیاں، اقتباسات، ابواب کا وقفہ، مطلع و مقطع کے کوئیک ٹیمپلیٹس۔
- **۳ متوازن تھیمز:** کاغذ (Sepia Parchment)، شبینہ (Dark Obsidian)، اور سادہ (Minimal Clean White)۔

## 🛠️ کمانڈز اور چلانے کا طریقہ (Commands & Scripts)

### لوکل ڈویلپمنٹ سرور چلائیں:
```bash
npm run dev
```

### پیداواری بلڈ (Production Build):
```bash
npm run build
```
*(یہ کمانڈ ماخذ دار لغت سے مطابقتی اثاثے بناتی ہے، پھر ٹائپ اسکرپٹ اور Vite بلڈ چلاتی ہے؛ یہ علمی توثیق کا متبادل نہیں۔)*

### فولڈر `qaafiyah 2` کو دوبارہ انضمام/اپڈیٹ کرنا:
```bash
node src/scripts/ingestQaafiyahFolder.js
```
